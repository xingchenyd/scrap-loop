# 废品轮回 Scrap Loop

一个以环保回收为主题的 2D 俯视角动作冒险游戏。玩家扮演废品回收志愿者，在电子、塑料、纸板、布料四大关卡中清理污染、收集碎片、升级装备与技能，最终挑战 Boss 并用碎片 3D 打印纪念品，完成循环再生的公益旅程。

## 快速开始

```bash
python -m http.server 4177 --bind 0.0.0.0
```

然后打开浏览器访问：

```text
http://127.0.0.1:4177/
```

## 操作说明

- WASD / 方向键：移动角色
- Space / 鼠标左键：攻击
- Q：释放技能（冷却 20 秒）
- Enter：对话推进 / 确认
- E：交互（设施、NPC）
- K：技能列表
- C：角色属性
- X：装备栏
- B：背包
- M：地图
- N：剧情导览
- Esc：关闭面板 / 取消

## 玩法特色

- 五幕主线剧情：序章 → 电子 → 塑料 → 纸板 → 布料 → 尾声，每幕有独立主题场景与怪物
- 四大废料主题：电子、塑料、纸板、布料，各有独立怪物图鉴与纪念品
- 合成与精炼系统：收集碎片后在精炼机中合成装备，在纪念工坊制作纪念品
- 技能系统：12 种主动技能，包括无敌回收罩、全屏净化波、低温泡沫、冲刺清扫等
- 10 种特效精灵动画：命中火花、挥砍弧光、爆炸、冰冻、闪电、毒云、枪口闪光、治疗光环、护盾屏障、能量涌动
- Boss 战：挑战蓝猫打印核心，净化污染源
- 任务系统：碎片回收、污染清障、Boss 净化等任务可获得碎片奖励
- 大世界探索：3200x2400 像素地图，含设施、传送门、隐藏区域

## 部署

推荐使用 GitHub Pages、Netlify Drop 或 Cloudflare Pages 部署。

GitHub Pages：

1. Fork 本仓库
2. 确认 `index.html`、`main.js`、`style.css`、`README.md` 及 `assets/` 目录完整
3. 在 `Settings -> Pages` 选择 `main` 分支并保存
4. 等待部署完成后访问生成的 URL
