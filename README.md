# 废品轮回 Scrap Loop

面向青少年的公益回收网页游戏原型。玩家在基地选择电子废料、塑料废料、纸板纸类、布料纺织四个主题，进入小怪、尸潮、解密或 Boss 关卡，收集碎片、升级装备、解锁技能、阅读废品故事卡牌，并用 Boss 掉落的打印碎片兑换 3D 废物打印纪念品券。

## 本地运行

```bash
python -m http.server 4177 --bind 0.0.0.0
```

打开：

```text
http://127.0.0.1:4177/
```

同一局域网其他电脑可打开本机局域网 IP，例如：

```text
http://你的电脑IP:4177/
```

## 操作

- WASD / 方向键：八方向移动
- Space / 点击画面：攻击
- Q / 手机“技能”：释放当前技能，统一 20 秒冷却
- Enter：互动、进入传送门、解密投放、通关后回基地
- E：装备间
- K：技能训练
- C：收藏品合成
- X：实物兑换
- B：背景终端
- M：公益任务
- N：通关小怪或尸潮后继续下一轮
- Esc：关闭面板，或退出关卡回基地安全区

## 当前玩法

- 四主题关卡：电子、塑料、纸板、布料会影响敌人、掉落、解密顺序、展馆卡牌和装备方向。
- 大地图战斗：关卡从固定小场地扩展为可移动地图，镜头跟随角色，随机 6 张地图氛围。
- 战斗系统：圆圈攻击、挥砍、追踪弹、多弹、穿透、缠绕、反伤、回血等效果。
- 尸潮模式：60 秒持续涌入敌人，场地刷新 buff，小怪只掉碎片。
- 解密关卡：按主题顺序拾取样本并投放到发光设备，学习分类流程。
- Boss 模式：击败蓝猫回收守卫获得打印碎片，用于兑换 3D 打印纪念券。
- 技能系统：12 个技能，基地解锁并选择，战斗中 Q 使用。
- 收藏展馆：卡牌风纪念品，每张卡都有废品自己的故事描述。
- 剧情导览：50 段“我与废品对话”场景，结合回收知识点与任务目标。

## 发布

项目是纯静态网页，所有资源都使用相对路径。可以部署到 GitHub Pages、Netlify Drop、Cloudflare Pages 或任意静态托管。

GitHub Pages：

1. 新建公开仓库。
2. 上传 `index.html`、`main.js`、`style.css`、`README.md` 和整个 `assets/` 文件夹。
3. 在 `Settings -> Pages` 中选择 `main` 分支和根目录发布。
4. 等待生成公网 URL。

Netlify Drop：

1. 打开 `https://app.netlify.com/drop`。
2. 上传整个 `recycle-quest` 文件夹内容。
3. 生成公网 URL 后，任何电脑可直接打开。

`.cn` 域名需要单独购买域名并完成解析，通常还涉及国内备案；当前版本先提供可直接部署的静态站点。

## 知识依据

剧情和卡牌故事围绕常见回收事实设计：电池和电子废弃物需要规范回收，塑料、纸板和纺织品的再利用受清洁度、材质混合、污染程度影响。后续可接入学校或公益机构的本地分类规则。
